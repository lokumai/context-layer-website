# Context Layer — Marketing Website

Static marketing landing pages for the Context Layer ecosystem.

## Development
```sh
bun dev
```
Starts the server on [localhost:3001](http://localhost:3001).

## Build
```sh
bun run build
```
Generates a static export in `out/`, suitable for GitHub Pages.

## Tech Stack
- Next.js 16 (Static Export)
- React 19
- Tailwind CSS v4
- Motion
- Shared components from `@context-layer/ui`
