## Principles we're adopting (from the samples)

These are the patterns worth borrowing. Record them here so every task has the same reference.

1. **Shadow states.** Cards should rest on `shadow-eleven-inset` (a half-pixel inset border + 1px outline ring, both sub-0.1 opacity) and transition to `shadow-eleven-card` (1px outline + 4px soft lift) on hover. Right now every card hard-codes the card shadow as the resting state, which makes them feel heavy.
2. **Bottom meta strip.** Cards that represent things-in-time (sources, library items, jobs) should end with a `border-t` divider + a micro-label / value / optional trailing chevron. This gives each card a terminal line that reads like a footnote.
3. **Icon language.** Replace the text tiles (`"Repo"`, `"Doc"`, `"PDF"`, `"Audio"`) with real icons. Use `lucide-react` at stroke 1.5, wrapped in a 12×12 `IconTile` with `bg-neutral-50` + `border border-neutral-100 rounded-xl`. Never color icons brand-heavily — pick achromatic black/neutral with occasional amber for warn states.
4. **Asymmetric headers on overview pages.** Wiki Status and Intelligence both benefit from a 2/3 title+subtitle on the left and a 1/3 sidebar callout on the right (active schema, sync heartbeat, "recent activity"). It reads like editorial layout and fills whitespace meaningfully.
5. **Bento, not uniform grids.** On pages with a clear primary + secondary (Wiki Status, Intelligence, DocsGen), use a 12-column grid with a `md:col-span-8` hero card and a `md:col-span-4` sidebar stack. Uniform 3-col grids are fine for lists (Sources, Library) but feel flat for overview pages.
6. **Chat bubble differentiation.** User messages: `bg-neutral-100` right-aligned pill. Agent messages: left-aligned with a small black-circle avatar containing a lucide icon; section heading in Waldenburg 300; citations as inline warm-stone chips + pill buttons. This gives conversations visible structure.
7. **Warm-stone inline chips for citations.** `bg-warm-stone px-2 py-0.5 rounded text-black font-medium border border-black/5` — distinctive, matches the CTA family.
8. **Global footer.** Thin, neutral-50, border-top, copyright + 3–4 legal links. The samples have it on every page; we don't. Adds closure.
9. **Inline empty-state "teach" panels.** Sources ends with a "Sync more context" neutral-50 24px-radius panel even when populated. It's a pedagogic hint — the page teaches the user the next action without nagging.
10. **Micro-labels.** `text-[10px]–text-[11px] uppercase tracking-widest font-bold text-neutral-400` for labels next to values. Appears on every card footer in the samples; gives the product a data-grade, editorial feel.

## What NOT to adopt

- Sample-specific copy, colors beyond DESIGN.md's palette, or brand references ("ElevenLabs", "Waveform Alpha"). Write our own copy.
- Material Symbols. We already depend on `lucide-react`; adding another icon font doubles bundle weight.
- Elaborate gradient blobs/backgrounds inside cards. Keep canvases pure white.
- Audio-waveform decoration. It's a sample flourish tied to the vendor's product, not ours.

```tsx
// apps/web/components/ui/card.tsx
import { forwardRef, type HTMLAttributes } from "react";
import clsx from "clsx";

type Variant = "inset" | "card" | "outline";

const VARIANT_CLASS: Record<Variant, string> = {
  inset: "shadow-eleven-inset hover:shadow-eleven-card transition-all duration-300",
  card: "shadow-eleven-card",
  outline: "shadow-eleven-outline",
};

export interface CardProps extends HTMLAttributes<HTMLDivElement> {
  variant?: Variant;
  padding?: "tight" | "comfortable" | "spacious";
  radius?: "card" | "section";
}

const PADDING: Record<Required<CardProps>["padding"], string> = {
  tight: "p-4",
  comfortable: "p-6",
  spacious: "p-8",
};

const RADIUS: Record<Required<CardProps>["radius"], string> = {
  card: "rounded-2xl",
  section: "rounded-[24px]",
};

export const Card = forwardRef<HTMLDivElement, CardProps>(function Card(
  { variant = "inset", padding = "comfortable", radius = "card", className, ...rest },
  ref,
) {
  return (
    <div
      ref={ref}
      className={clsx(
        "bg-white",
        PADDING[padding],
        RADIUS[radius],
        VARIANT_CLASS[variant],
        className,
      )}
      {...rest}
    />
  );
});
```

If `clsx` is not already available, fall back to a tiny local join helper — do not add a new dep for this.

```tsx
// apps/web/components/ui/icon-tile.tsx
import type { LucideIcon } from "lucide-react";

export function IconTile({ icon: Icon, size = "md", tone = "neutral" }: {
  icon: LucideIcon;
  size?: "sm" | "md" | "lg";
  tone?: "neutral" | "dark";
}) {
  const box =
    size === "sm" ? "w-10 h-10 rounded-lg" : size === "lg" ? "w-14 h-14 rounded-xl" : "w-12 h-12 rounded-xl";
  const iconSize = size === "sm" ? 18 : size === "lg" ? 28 : 24;
  const bg = tone === "dark" ? "bg-black text-white" : "bg-neutral-50 border border-neutral-100 text-black";
  return (
    <div className={`${box} ${bg} flex items-center justify-center`}>
      <Icon size={iconSize} strokeWidth={1.5} />
    </div>
  );
}
```

```tsx
// apps/web/components/ui/pill-button.tsx
import { forwardRef, type ButtonHTMLAttributes } from "react";
import clsx from "clsx";

type Variant = "primary" | "warm" | "white" | "ghost";

const VARIANT_CLASS: Record<Variant, string> = {
  primary: "bg-black text-white hover:opacity-80",
  warm: "bg-warm-stone shadow-eleven-warm hover:opacity-90",
  white: "bg-white shadow-eleven-card hover:bg-neutral-50",
  ghost: "text-neutral-500 hover:text-black hover:bg-neutral-100",
};

export interface PillButtonProps extends ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: Variant;
  uppercase?: boolean;
  size?: "sm" | "md" | "lg";
}

const SIZE: Record<Required<PillButtonProps>["size"], string> = {
  sm: "px-4 py-1.5 text-[13px]",
  md: "px-6 py-2 text-[14px]",
  lg: "px-8 py-3 text-[14px]",
};

export const PillButton = forwardRef<HTMLButtonElement, PillButtonProps>(function PillButton(
  { variant = "primary", uppercase = false, size = "lg", className, ...rest },
  ref,
) {
  return (
    <button
      ref={ref}
      className={clsx(
        "rounded-full font-medium transition-all disabled:opacity-40",
        SIZE[size],
        VARIANT_CLASS[variant],
        uppercase && "font-waldenburg-bold uppercase tracking-[0.7px]",
        className,
      )}
      {...rest}
    />
  );
});
```
